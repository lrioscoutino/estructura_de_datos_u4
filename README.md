# Unidad 4 — Estructuras no lineales

**Materia:** Estructura de Datos (AED-1026)
**Grupo:** S3C — Aula ED12
**Lenguaje:** Python 3

Continuación directa de la [Unidad 3](../estructura_de_datos_u3/README.md): ahí viste estructuras **lineales** (pilas, colas, listas), donde cada elemento tiene un único predecesor y un único sucesor. Esta unidad entra a las estructuras **no lineales**, donde un elemento puede conectarse con varios otros a la vez: árboles (conexiones jerárquicas, sin ciclos) y grafos (conexiones libres, con o sin ciclos).

## Contenido

- [02_practica_arboles_grafos.md](02_practica_arboles_grafos.md) — Práctica guiada paso a paso: 4.1 clasificación de árboles, operaciones básicas sobre árboles binarios (insertar/buscar/recorridos inorden-preorden-postorden), aplicaciones de árboles · 4.2 representación de grafos (lista de adyacencia), operaciones básicas (BFS, DFS, Dijkstra), aplicaciones de grafos
